## About the Project

The **Digital Wallet System** is a modern web application designed to manage user wallets, transactions, and financial data securely and efficiently.  

It leverages **Radix UI** for accessible components, **TailwindCSS** for rapid styling, **Redux Toolkit** for state management, and **React Hook Form** with **Zod** for form validation.  

The app supports **user authentication**, **wallet management**, **transactions**, **analytics**, and **notifications**, making it a complete solution for digital payments.

---

## Features

- ✅ User registration, login, and authentication with JWT  
- ✅ Wallet creation and management  
- ✅ Transactions: send, receive, deposit, withdraw  
- ✅ Transaction history and analytics dashboard  
- ✅ Form handling with `react-hook-form` and `zod` validation  
- ✅ Responsive UI with **TailwindCSS**  
- ✅ Modular, accessible UI components using **Radix UI**  
- ✅ State management with **Redux Toolkit**  
- ✅ API integration with **Axios**  
- ✅ Notifications using **Sonner**  
- ✅ Animations using **Framer Motion**

## Installation

1. Clone the repository:

```bash
git clone https://github.com/nodeNINJAr/Digital-Wallet-System-frontend
cd digital-wallet-system


2 .Install dependencies:

npm install


3. Start the development server:

npm run dev


The app should now be running at http://localhost:5173.

Usage

Register or log in to access your wallet

Create, send, and receive funds

View transaction history and analytics dashboard

Experience smooth animations and real-time notifications
